# Arduino Sensor Control — управление ультразвуковым датчиком через Windows Forms

Курсовой проект по дисциплине «Программирование интерфейсов вычислительных систем».
Приложение на C# (Windows Forms) обменивается данными с платой **Arduino UNO** по последовательному порту (COM) и управляет системой на основе ультразвукового дальномера: RGB-светодиодом и пьезодинамиком.

## Как это работает

1. Arduino постоянно измеряет расстояние ультразвуковым дальномером (HC-SR04).
2. Если расстояние меньше заданного порога — включается красный свет и звуковой сигнал (пищалка), иначе горит зелёный.
3. Windows Forms приложение подключается к Arduino по COM-порту, отображает текущее состояние и позволяет:
   - выбрать COM-порт и подключиться/отключиться;
   - задать порог срабатывания (ползунком или полем ввода) и отправить его на плату;
   - протестировать пищалку и RGB-светодиод по кнопке;
   - переключать автоматический/ручной режим.

Обмен данными идёт в виде текстовых команд через `SerialPort` (скорость 9600 бод).

## Схема подключения (Arduino)

| Пин Arduino | Назначение |
|---|---|
| 12 (Trig) | Отправка ультразвукового импульса (HC-SR04) |
| 11 (Echo) | Приём отражённого сигнала (HC-SR04) |
| 7 | Пьезодинамик (buzzer) |
| 4 | Красный канал RGB-светодиода |
| 3 | Зелёный канал RGB-светодиода |
| 2 | Синий канал RGB-светодиода |

## Протокол команд (ПК → Arduino)

| Команда | Действие |
|---|---|
| `SET_THRESHOLD:<число>` | Установить порог срабатывания в см (допустимо 5–100) |
| `GET_SETTINGS` | Запросить текущие настройки (порог, состояние пищалки/светодиода, режим) |
| `TEST_BUZZER` | Тестовый сигнал пищалки (0.5 сек) |
| `TEST_LED` | Тестовое переключение RGB-светодиода (красный → зелёный → синий) |
| `MODE:AUTO` | Включить автоматический режим (реакция на датчик) |
| `MODE:MANUAL` | Включить ручной режим (пищалка выключена, светодиод зелёный) |

Arduino, в свою очередь, присылает на ПК строки вида `DIST:<см>`, `LED:RED`/`LED:GREEN`, `BUZZER:ON`/`BUZZER:OFF`, `THRESHOLD:<число>`, `MODE:AUTO`/`MODE:MANUAL`.

## Требования

**Для Arduino:**
- Плата Arduino UNO (или совместимая)
- Ультразвуковой дальномер HC-SR04
- RGB-светодиод (общий катод) и резисторы
- Пьезодинамик (buzzer)
- [Arduino IDE](https://www.arduino.cc/en/software)

**Для Windows Forms приложения:**
- Windows
- [.NET SDK 8.0](https://dotnet.microsoft.com/download) или Visual Studio 2022+ с поддержкой .NET Desktop Development

## Запуск

1. **Прошивка Arduino:**
   - Соберите схему согласно таблице пинов выше.
   - Откройте `sketch_arduido.ino` в Arduino IDE, выберите плату и COM-порт, загрузите скетч.

2. **Запуск приложения:**
   - Откройте `WinFormsApp1.sln` в Visual Studio (или выполните `dotnet run` в папке проекта).
   - Соберите и запустите проект.
   - В приложении выберите нужный COM-порт из списка и нажмите «Подключиться».
   - Задайте порог срабатывания и нажмите «Установить», либо протестируйте пищалку/светодиод соответствующими кнопками.

## Технологии

- C#, Windows Forms, `System.IO.Ports.SerialPort`
- Arduino (C++/Arduino Core), библиотека для работы с HC-SR04 через `pulseIn`
